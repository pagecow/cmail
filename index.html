Gmail connection
One-time setup:
  1. Create a project at console.cloud.google.com and enable the Gmail API.
  2. Configure the OAuth consent screen (External) and add your own email as a test user.
  3. Create credentials → OAuth client ID → Desktop app.
  4. Add the Redirect URI above as an authorized redirect URI, then paste the Client ID and Secret here.
While the Cloud project is in Testing status, Google expires the connection after 7 days — just reconnect. Publishing the app removes that limit.
